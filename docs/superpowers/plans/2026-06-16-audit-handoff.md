## Задачи по приоритету

### 1. Охота на скрытые баги в слое провайдеров (read + reason + добить тестами)
Файлы: `scripts/factory/providers/{base,wavespeed,runware,openrouter,__init__}.py`. Проверить логикой и, где не покрыто, добавить юнит-тесты (моки сетевого шва):
- `base.wait`: множества `_POLLING`/`_FAILED`, timeout (включая 0), что неизвестный непустой статус трактуется как терминальный; `download`: атомарная запись, очистка `.tmp` при ошибке, проверка `dest.exists()`, провал на `_FAILED`/пустой result_url.
- `base.estimate_media_cost` (в `models.py`): все ветки — flat / scaled (×1.4 WS, ×2.25 RW·OR) / image flat; выбор тира (явный и `default_tier`); ошибки при отсутствии provider/res_mult/usd_per_sec/usd_per_image; image без duration.
- WaveSpeed: маршрутизация v3-JSON vs `api: v1_multipart`; настраиваемые имена полей кадров (`media.{start,end}`, дефолт image/end_image); `_encode_multipart` (границы, CRLF, финальный boundary, бинарные данные); `_file_part` отвергает http/data-URI.
- Runware: массив задач, `taskUUID` как job_id, poll через `getResponse`, `_status` (videoURL/imageURL→completed, errors→failed), data-URI кадров ОК (подтверждено докой).
- OpenRouter: только видео (image→ProviderError), frame_images first/last_frame, poll URL.
- Все `*Error` наследуют `ProviderError` и ловятся в `generate_batch` (`except ProviderError`).
