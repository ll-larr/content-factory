## Решения, принятые в ходе выполнения (не отступать без причины)

- `higgsfield auth login` и всё, что тратит кредиты, — только с участием/подтверждением пользователя.
- Quality-ревью пропускается только для задач без кода (как Task 1); для кода — всегда оба ревью.
- Фиксы ревью — отдельным коммитом (`fix: ...`), с повторным ревью.
- У пользователя bypass permissions — системные установки разрешены, но новые ставить через winget с фиксацией в этом файле.
