## 4. Правила работы (накопленные договорённости — соблюдать)

1. **Траты — только с явного подтверждения бюджета пользователем.** Перед любой
   живой генерацией называть сумму. Skeleton-гейт в коде сам блокирует траты
   (generate_batch → код 2), не обходить его.
2. **Граф-первый процесс:** перед правкой файла — запрос обратных рёбер по
   `.understand-anything/knowledge-graph.json` (impact-анализ), навигация через
   слои/рёбра вместо сплошного grep. Но граф — снимок/приближение:
   load-bearing факты проверять по реальному коду. После серии правок —
   инкрементальный `/understand`.
3. **Тесты:** `.\.venv\Scripts\python.exe -m pytest -q` из корня репо, venv не
   активировать. Перед коммитом — зелёные.
4. **Изоляция провайдера:** точные эндпоинты/model-id/поля — ТОЛЬКО в
   `scripts/factory/providers/<name>.py` + `knowledge/<name>-api.md`. Ключи из env.
5. **Процесс:** TDD; крупные фичи — superpowers:subagent-driven-development.
   Фаза 4 (звук) — НЕ писать код без отдельного brainstorming → writing-plans.
6. **Статус сверять по документам и git log, не по памяти** (роадмап,
   progress-доки, карточки knowledge/).
7. Технические нюансы, добытые спайками (не терять):
   - WaveSpeed `resolution_style` в карточке: `size` (flux/seedream/z_image —
     только "W*H"), `k` (nano-banana — 0.5k/1k/2k/4k), `omit` (kling);
     иначе кадры молча выходят квадратными или HTTP 400.
   - vidu q2 turbo на WS: поля `image`/`last_image`; цена нелинейна —
     720p = (duration−1)×$0.05, 5с = $0.20.
   - Каталог WaveSpeed `GET /api/v3/models` отдаёт base_price+formula — цены
     сверять БЕСПЛАТНО до генерации; есть и `GET /api/v3/balance`.
   - OpenRouter: скачивание видео требует Bearer (уже пофикшено в адаптере);
     Seedance на OR — токенная цена, наш flat/scaled её не выражает.
   - Латентный нюанс (не пофикшен): WaveSpeed отдаёт JPEG, а кадр сохраняется
     как `.png` — контент верный, расширение врёт.
