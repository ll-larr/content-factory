# content-factory

ИИ-конвейер создания видео: от одной фразы про тему до готовой серии со звуком,
субтитрами и сведённой громкостью.

Всё делается в локальной панели на `127.0.0.1` — от создания проекта до
собранного эпизода. Каждая платная стадия показывает смету **до** траты, а
результат ждёт приёмки: принять или отклонить с причиной.

- **Что это умеет** — [Функционал](#функционал)
- **Как устроено внутри** — [ARCHITECTURE.md](ARCHITECTURE.md)

## Первый запуск

Нужны **Python 3.12+**, **Node 20+** и **ffmpeg**. Ниже — по системам; шаги
одинаковые, различаются только команды.

### Windows

```powershell
git clone https://github.com/ll-larr/content-factory.git
cd content-factory

# 1. Python: конвейер, гейты, провайдеры
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

# 2. Node: монтаж на Remotion
npm install --prefix montage
```

ffmpeg, если его нет:

```powershell
winget install Gyan.FFmpeg
```

Запуск панели — **двойным кликом по `panel.cmd`** или из терминала:

```powershell
.venv\Scripts\python.exe scripts\serve.py
```

Окно с панелью откроется само. Терминал не закрывать: он и есть сервер, `Ctrl+C`
останавливает.

### macOS

```bash
git clone https://github.com/ll-larr/content-factory.git
cd content-factory

# 1. Python: конвейер, гейты, провайдеры
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt

# 2. Node: монтаж на Remotion
npm install --prefix montage
```

ffmpeg и Node, если их нет:

```bash
brew install ffmpeg node
```

Запуск панели — **двойным кликом по `panel.command`** в Finder или из терминала:

```bash
./.venv/bin/python scripts/serve.py
```

Если Finder отказывается запускать файл, верните ему право на выполнение:

```bash
chmod +x panel.command
```

macOS может сказать «не удаётся проверить разработчика» — снимите карантин:

```bash
xattr -d com.apple.quarantine panel.command
```

### Linux

Как на macOS, только ffmpeg и Node ставятся пакетным менеджером:

```bash
sudo apt install ffmpeg nodejs npm
```

Лаунчер тот же — `panel.command`.

### Проверка, что всё встало

Панель при старте сама печатает, чего не хватает, и показывает это баннером в
браузере: ffmpeg, Node, npx, зависимости монтажа. Ревью кадров работает и без
ffmpeg — не встанет только монтаж.

Тесты (нужны оба набора):

```bash
.venv/Scripts/python.exe -m pytest -q     # Windows
./.venv/bin/python -m pytest -q           # macOS / Linux
npm test --prefix montage
```

### Если текстовая стадия отвечает «движок отказал»

`Failed to authenticate. API Error: 401` или `403` — это Claude Code на машине
не авторизован. Лечится в терминале:

```bash
claude auth login
```

Команда открывает браузер, поэтому из панели её не запустить. Учтите:
`claude auth status` в этом состоянии может отвечать `loggedIn: true` — верить
надо самому вызову, а не статусу.

Второй путь, если Claude Code не нужен вовсе: задать `OPENROUTER_API_KEY` во
вкладке «Ключи» и выбрать в панели движок «Модель по ключу OpenRouter». Тогда
текстовые стадии идут по ключу, а Claude Code не участвует.

### Ключи провайдеров

Вводятся во вкладке **«Ключи»** прямо в панели и пишутся в `.env` рядом с
проектом — файл не попадает в репозиторий. Можно и вручную: скопировать
`.env.example` в `.env`.

| переменная | за что отвечает | обязательна |
|---|---|---|
| `RUNWARE_API_KEY` | кадры и видеоотрезки | для генерации картинки |
| `WAVESPEED_API_KEY` | речь, музыка, эффекты, липсинк | для звука |
| `OPENROUTER_API_KEY` | ещё один поставщик видео; движок текстовых стадий | если нет Claude Code |
| `TAVILY_API_KEY` | поиск для проверки фактов | только познавательный жанр без Claude Code |

Нужен только ключ того провайдера, который выбран в проекте. Отсутствующий ключ
конвейер ловит **до** сметы и отказывается работать, а не падает на середине
оплаты.

## Функционал

### Проект создаётся в панели

Мастер «+ Новый проект» спрашивает формат, жанр, имя, тему, язык и количество
серий — и заводит дерево целиком: бриф, манифест, библию, каталоги серий.

**Форматы:** горизонтальный 16:9 и вертикальный шортс 9:16. Полный метр — это
сериал из одной серии.

**Жанры** (мультфильм, аниме, кино и сериал, познавательное) — не слово в
конфиге, а данные: жанр решает, какие стадии вообще существуют, есть ли
персонажи, допустим ли липсинк, нужны ли субтитры и обязательна ли проверка
фактов. Панель перестраивается под жанр: у познавательного нет «Персонажей», зато
есть «Проверка фактов».

### Одна кнопка «Запустить конвейер»

Панель всегда знает, какой шаг следующий, и кнопка запускает именно его. На
пустом проекте это первая фаза — та, которую требует жанр: у познавательного
исследование источников, у повествовательных идея и библия. Дальше кнопка ведёт
по сценарию, проверке фактов, персонажам, раскадровке и съёмке.

Платная стадия из этой же кнопки сначала показывает смету и ждёт подтверждения —
своего порядка стадий у панели нет, она спрашивает тот же резолвер, что и CLI.

### Текст пишет агент или модель по ключу

Идея, библия, сценарий, карточки персонажей, раскадровка и план звука пишутся из
поля внизу панели. Движка два: **Claude Code**, если он есть на машине, иначе
**модель по ключу OpenRouter** — её человек выбирает сам, с ценой за миллион
токенов из живого каталога.

Методика одна на оба пути: промптом становится тело того же скилла из
`.claude/skills/`, по которому работает агент.

### Проверка фактов познавательного жанра

Сценарий проверяет **отдельный вызов в пустом контексте**: он не видел, как
сценарий сочинялся. Правила жёсткие — не верить источнику автора, подтверждать
каждый факт минимум пятью независимыми источниками, расхождения исправлять с
объяснением.

Работает в два прохода: проверяющий называет утверждения и поисковые запросы,
код ищет, проверяющий выносит вердикт. Ищет либо Claude Code своими
инструментами, либо код по ключу Tavily. **Без пройденной проверки сценарий не
одобряется** — панель показывает состояние, число утверждений, источники
ссылками и весь отчёт.

### Артефакты открываются по клику

Идея, сквозной сюжет, стайл-гайд, сценарии, карточки персонажей, отчёт проверки
фактов — всё в таблице «Тексты» кликабельно: клик открывает содержимое прямо в
панели. Одобрение остаётся отдельной кнопкой: `status` ставит только `approve`.

### Съёмка с приёмкой и сметой

Кадры, отрезки, озвучка, музыка, эффекты, фоли, липсинк. Перед каждой стадией —
смета по фактическим ценам карточек; после — приёмка: принять, принять с
замечаниями или отклонить с причиной. Отклонённое переснимается.

Задача принадлежит серверу, а не вкладке: закрытый браузер не обрывает
оплаченную съёмку, а вторая стадия при активной первой отбивается.

### Дешёвый режим «кадры»

Эпизод собирается без единого видеоотрезка: кадры под озвучку с медленным
наездом, длительность кадра равна его реплике. Примерно **в десять раз дешевле**
съёмки и для познавательного жанра — норма, а не экономия.

### Выбор моделей по ролям

Вкладка «Модели»: по роли (кадры, отрезки, озвучка, музыка, эффекты, фоли,
липсинк) — список с ценой, посчитанной под этот проект. Модель, чьи возможности
и цена не подтверждены живой генерацией, видна, но не выбирается; недоступное
объясняет себя.

### Кастинг голосов

Вкладка «Голоса»: пресеты модели речи деревом «модель → пол → голос», у каждого
маркеры (тон, тональность, применение) и кнопка «играть». Все читают одну и ту
же фразу — сравнивать тембры можно только на одинаковом тексте. Пробы снимаются
одной кнопкой и хранятся рядом с карточкой модели.

### Микшер

Вкладка «Микшер»: громкости пяти дорожек (речь, эффекты, подложка, музыка,
фоли), выключение любой, множитель громкости на каждого героя, дакинг (глубина,
атака, спад) и цель мастеринга в LUFS.

### Монтаж

Сборка эпизода одной командой или кнопкой: склейка, сведение звука, субтитры,
оформление вертикали, мастеринг громкости до −14 LUFS. Формат сборки берётся из
проекта.

Монтаж живёт в [Remotion](https://remotion.dev). Python отдаёт монтажный лист —
намерение: какие файлы, в каком порядке, с какой громкостью. Факты о медиа
(длительности, размеры, fps) выясняет сам монтаж.

### Деньги

Цены записаны в карточках моделей и подтверждены живыми списаниями. Карточка со
статусом `skeleton` блокирует трату до живой проверки. Сводная смета складывает
остаток работ по эпизоду и не считает уже принятое. У проекта есть потолок
бюджета, и код останавливает съёмку, а не урезает её молча.

## Команды

Панель запускает ровно эти команды — в терминале доступно то же самое.

```bash
# состояние проекта и следующий шаг
python scripts/factory.py status  --project projects/<проект>
python scripts/factory.py next    --project projects/<проект>
python scripts/factory.py check   --project projects/<проект> --stage script --episode ep01
python scripts/factory.py approve --project projects/<проект> episodes/ep01/script.md
python scripts/factory.py estimate --project projects/<проект> --episode ep01

# текстовая стадия
python scripts/text_stage.py --project projects/<проект> --stage story
python scripts/text_stage.py --project projects/<проект> --stage factcheck --episode ep01

# генерация (платно, со сметой)
python scripts/generate_batch.py --project projects/<проект> --episode ep01 --stage storyboard
python scripts/generate_batch.py --project projects/<проект> --episode ep01 --stage segments

# приёмка
python scripts/review.py --project projects/<проект> list --status generated
python scripts/review.py --project projects/<проект> accept ep01/segments/001

# монтаж
python scripts/render.py --project projects/<проект> --episode ep01

# пробы голосов
python scripts/voice_samples.py --model gemini_2_5_pro_tts --language ru
```

Все команды запускаются **из корня репозитория**.

## Структура

```
scripts/            конвейер и панель
  factory.py          состояние, гейты, одобрения, смета
  generate_batch.py   генерация кадров, отрезков и звука
  review.py           приёмка
  render.py           монтаж эпизода
  text_stage.py       текстовая стадия одной командой
  voice_samples.py    пробы голосов
  serve.py            панель (локальный веб-интерфейс)
  factory/            ядро: состояние, модель данных, деньги, безопасность
    providers/        адаптеры провайдеров
    text/             движки текста, стадии, проверка фактов
montage/            монтаж на Remotion — единственное место с Node и React
web/                панель: три файла статики
knowledge/          карточки моделей, жанров и голосов, контракты провайдеров
projects/           контент-проекты (пуст в репозитории)
.claude/skills/     методика текстовых стадий
tests/              pytest
```

## Ограничения

- Панель слушает только `127.0.0.1` и не имеет аутентификации: она даёт полный
  доступ к проектам и тратит деньги. В сеть выставлять нельзя.
- Липсинк и разрешение 1080p не подтверждены живой генерацией — соответствующие
  карточки заблокированы гейтом трат.
- Выбранный голос вписывается в план звука вручную; предпрослушки сведения нет.
