# План звука (audio.json)

## Перед работой

1. Прочитай `episodes/<ep>/script.md`. Реплики и звуковые ремарки в квадратных
   скобках — уже написаны там, придумывать их заново не надо.
2. Прочитай `episodes/<ep>/shots.json`: номера отрезков и что в каждом
   происходит. Тайминг звука задаётся отрезком и смещением внутри него.
3. Прочитай карточки персонажей: поле `voice` — это ЛИЧНОСТЬ голоса, она
   одна на весь сезон.
4. Прочитай `bible/craft-notes.md`, группа «Звук», если она есть.

## Что написать

`episodes/<ep>/audio.json` — обычный JSON, контракт в
`scripts/factory/audio_plan.py`. Не frontmatter-артефакт: `kind`/`status` у него
нет, `factory.py approve` на нём не работает.

Четыре списка, все необязательные:

```json
{
  "voice_lines": [
    {"id": "vl-04", "speaker": "Устинья", "voice": "Kore",
     "direction": "flat, decision already made, no emotion",
     "text": "Так.", "segment": 4, "offset": 1.2, "lipsync": true}
  ],
  "music_cues": [
    {"id": "mus-01", "prompt": "sparse cold drone, single low cello",
     "duration": 60, "segment": 1, "offset": 0,
     "envelope": [[0, 0.0], [4, 1.0]]}
  ],
  "sfx": [
    {"id": "sfx-05", "prompt": "distant ship horn through fog, long",
     "duration": 4, "segment": 5, "offset": 0.5,
     "envelope": [[0, 0.2], [1, 1.0], [4, 0.3]]}
  ],
  "foley": [
    {"id": "fol-08", "segment": 8, "prompt": "boots and dragging sheet metal on stone stairs"}
  ]
}
```

## Правила, выведенные живыми пробами

Эти пять фактов проверены генерацией 2026-09-04. Нарушение каждого стоит денег
и переделки.

1. **Единица — реплика целиком, а не слово.** Собирать фразу из отдельно
   сгенерированных кусков нельзя: между вызовами меняется интонация и стык
   слышен.
2. **Разметки внутри текста нет.** Теги `<sigh>`, `[пауза]`, звёздочки модель
   читает ВСЛУХ как слова. Вся подача — прозой в `direction`.
3. **Подряд идущие повторы одного слова звучат одинаково.** «Мало. Мало. Мало.»
   выходит тремя одинаковыми словами, и указание «ступенькой вниз» не помогает.
   Если в сценарии есть такой повтор — либо оставь одно слово, либо разнеси
   повторы по РАЗНЫМ отрезкам отдельными единицами.
4. **`voice` — только личность, `direction` — только подача.** Смешаешь их в
   одном поле — правка интонации одной сцены уедет в тембр персонажа, и он
   поплывёт между сериями.
5. **Слова про дыхание в описании исполняются буквально.** «Говорит на выдохе»
   даёт вздыхание в каждой фразе. Описывай задачу, а не физиологию.

## `direction` — режиссёрские пометки

Пиши по предложениям, как замечания актёру: что за состояние, кому адресовано,
громче или тише предыдущего. Пример, который сработал:

> `'Так' is one flat syllable, a decision already made, no emotion. The next
> sentence is grumbled sideways to nobody, quicker, thrown away.`

Английский: модель понимает инструкцию на английском надёжнее, а озвучивает
русский текст. Сам `text` — по-русски.

## `voice` — имя пресета

Тридцать голосов Gemini: Achernar, Achird, Algenib, Algieba, Alnilam, Aoede,
Autonoe, Callirrhoe, Charon, Despina, Enceladus, Erinome, Fenrir, Gacrux,
Iapetus, Kore, Laomedeia, Leda, Orus, Puck, Pulcherrima, Rasalgethi, Sadachbia,
Sadaltager, Schedar, Sulafat, Umbriel, Vindemiatrix, Zephyr, Zubenelgenubi.

**Не угадывай голос по имени** — имена ничего не говорят о тембре. Голос
персонажа выбирает человек по пробам; если в карточке персонажа пресет ещё не
записан, спроси, а не подставляй Kore по умолчанию.

## `envelope` — движение уровня

Список точек `[секунда_от_начала_единицы, уровень]`, уровень 0..2, время не
убывает. Нужен там, где звук приближается, отдаляется или уходит в тишину:
уходящий гудок — падающая огибающая, накатывающий шторм — растущая.

Без огибающей громкость постоянная. Не ставь её ради красоты: постоянная
громкость дешевле в рендере.

## `sfx` против `foley`

- `sfx` — звук, которого в кадре НЕ ВИДНО: гудок баркаса из тумана, щелчок
  перегоревшей лампы, море за кадром. Ставится точным смещением, потому что
  несёт смысл.
- `foley` — то, что в кадре видно и должно звучать: шаги, жесть, ткань,
  ступени. Генерируется по самому отрезку и синхронен по построению.

Одна дорожка фоли на отрезок, не больше. Фоли нужен не каждому отрезку: там,
где в кадре ничего не движется, он даст шум вместо фактуры.

## `lipsync`

Ставь `true` ТОЛЬКО там, где лицо говорящего видно крупно и губы читаются.
Липсинк стоит дороже самой реплики в несколько раз, а на спине, общем плане и
жестяной птице с неподвижным клювом он бессмыслен.

## После записи

1. Проверь план валидатором — он ловит опечатки до трат:
   ```bash
   python scripts/generate_batch.py --project <проект> --episode <ep> --stage audio
   ```
   Смета печатается до генерации; отказ по контракту — код 2.
2. Закоммить план сразу:
   ```bash
   git add <проект>/episodes/<ep>/audio.json
   git commit -m "draft(preprod): audio <ep> <проект>"
   ```
