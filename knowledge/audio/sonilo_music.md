# Sonilo Music — фоновая музыка по настроению

> **ИСТОРИЧЕСКАЯ КАРТОЧКА (эпоха Higgsfield).** Генерация звука вынесена в отдельную
> задачу; стадия audio в конвейере отключена. Сохранена как референс по музыке
> (формат, поведение) для будущей audio-интеграции; mix_audio/assemble — без изменений.

Генерация музыки по текстовому описанию настроения + длительности (спека фазы 2 §5,
закрыт открытый вопрос §16.2 основной спеки — музыка генерацией).

## Параметры (историческое, Higgsfield CLI)

- prompt — настроение/жанр (обязателен), напр.
  `"playful orchestral space adventure, cartoon style"`.
- duration — секунды (обязателен; дробные допустимы).

## Стоимость (историческое, Higgsfield)

Была линейна по длительности (дешёвый аудио-компонент). Для будущей audio-интеграции
тарификация — своя.

## Формат выхода (проверено генерацией 2026-06-13)

`result_url` → файл **.m4a** (codec **aac**, **stereo**, 44.1 кГц). Длительность
близка к запрошенной (duration=5 → 5.06с). Пример: spike/audio/sonilo_music.m4a (185 КБ).

⚠️ Формат (.m4a) ОТЛИЧАЕТСЯ от Mirelo (.mp3) — расширение брать из `result_url`,
а не из единой константы (урок для будущей audio-интеграции).
