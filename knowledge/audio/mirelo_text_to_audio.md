# Mirelo Text to Audio — звуковые эффекты (SFX)

> **ИСТОРИЧЕСКАЯ КАРТОЧКА (эпоха Higgsfield).** Генерация звука вынесена в отдельную
> задачу; стадия audio в конвейере отключена. Сохранена как референс по SFX (формат,
> поведение) для будущей audio-интеграции; mix_audio/assemble работают с любыми файлами.

Генерация SFX по текстовому описанию + длительности (спека фазы 2 §5).

## Параметры (историческое, Higgsfield CLI)

- prompt — описание эффекта (обязателен), напр. `"rocket thruster whoosh"`.
- duration — секунды (обязателен; дробные допустимы).

## Стоимость (историческое, Higgsfield)

Была линейна по длительности. Для будущей audio-интеграции тарификация — своя.

## Формат выхода (проверено генерацией 2026-06-13)

`result_url` → файл **.mp3** (codec mp3, **mono**, 44.1 кГц). Длительность близка
к запрошенной (duration=2 → 2.02с). Пример: spike/audio/mirelo_sfx.mp3 (16 КБ).

## Наблюдения

- Генерация быстрая (единицы секунд), `--wait` отрабатывает мгновенно.
- Качество звука НЕ оценивалось (нет слуха у ассистента) — прослушать на ревью.
- Списание совпало со сметой; провалившиеся задачи (см. карточку Inworld) НЕ списывают.
