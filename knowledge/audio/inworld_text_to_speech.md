# Inworld Text to Speech — реплики и закадр (TTS)

> **status: skeleton — генерацией НЕ верифицирована.** Блокер: формат значения
> параметра `voice` для интеграции Higgsfield неизвестен (см. ниже). Перевести
> в `verified` после первой успешной генерации.

## Параметры CLI (`model get`)

- `--prompt` — текст реплики (обязателен).
- `--voice` — идентификатор голоса (обязателен, string). **Сметой НЕ валидируется**
  (любая строка даёт смету 2 кр).

## Стоимость

**2 кр/генерация, плоско** — от длины текста не зависит (проверено сметой до ~350
символов и длинного абзаца). Вывод для экономики: дорого для множества коротких
реплик, выгодно для длинного закадра. План перехода TTS на ElevenLabs при
≥2–4 серий/мес — спека фазы 2 §3.

## 🚧 БЛОКЕР: формат `voice` (спайк 2026-06-13)

Простые имена голосов Inworld, которые принимает родной API Inworld
(Ashley, Hades, Olivia, Dennis, Mark, lowercase `ashley`), в CLI Higgsfield
дают **`status: failed`** — пустой `result_url`, без текста ошибки в `generate get`.

Проверенные факты:
- **Провалившаяся генерация НЕ списывает кредиты** (баланс не менялся через 6 неудачных
  попыток) — голоса можно перебирать бесплатно, спишется только первый успешный (2 кр).
- Mirelo и Sonilo (тот же тип `audio`, без `voice`) генерируются успешно → проблема
  именно в формате значения `voice`, не в аудио-конвейере в целом.
- CLI не имеет команды листинга голосов (`model get` отдаёт только тип string без enum;
  нет подкоманды `voice`). Публичные доки Higgsfield аудио/голоса не покрывают.

**Гипотеза:** Higgsfield ждёт собственный идентификатор голоса (UUID/слаг из своего
каталога), доступный только в авторизованном веб-UI (Speak/Audio, выпадающий список
голосов). Нужно: взять рабочее значение `--voice` из веб-UI (или сетевого запроса
при выборе голоса) и подставить. Кандидаты-имена Inworld для перебора, когда формат
прояснится: Ashley (warm/friendly), Hades (deep/commanding), Sarah, Timothy, Olivia,
Dennis, Elizabeth, Pixie, Dominus, Luna — всего ~25 английских; русский — отдельно
(Inworld TTS-1.5 держит русский в production).

## Что записать после разблокировки

- Точный формат `--voice` (пример рабочего значения).
- Выходной формат файла (mp3/m4a/wav) → обновить `output_format` и логику расширения.
- Поведение русского текста; качество голосов (прослушать на ревью).
