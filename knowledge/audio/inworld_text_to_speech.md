# Inworld Text to Speech — реплики и закадр (TTS)

> **ИСТОРИЧЕСКАЯ КАРТОЧКА (эпоха Higgsfield).** Inworld TTS через Higgsfield CLI
> оказалась нефункциональной (спайк 2026-06-13: все голоса → `failed`). Стадия
> audio в конвейере отключена; **решение — TTS на ElevenLabs отдельной задачей**
> (эту карточку в конвейере не использовать). Ниже — историческая диагностика.

## Параметры (историческое, Higgsfield CLI)

- prompt — текст реплики (обязателен).
- voice — идентификатор голоса (обязателен). Сметой НЕ валидировался
  (любая строка проходила смету, но генерация падала).

## Стоимость (историческое, Higgsfield)

Неудачные TTS-вызовы на Higgsfield по факту были бесплатны (списание автоматически
возвращалось рефандом). Для будущей интеграции на ElevenLabs тарификация — своя.

## 🚧 БЛОКЕР: модель не генерирует ни с одним голосом (спайк 2026-06-13)

Испробованы значения `--voice`: `Ashley`, `Hades`, `Olivia`, `Dennis`, `Mark`,
`ashley`, **`ava`, `Ava`** — ВСЕ → `status: failed`, пустой `result_url`, без текста
ошибки, с авто-рефандом. При этом:
- **Mirelo и Sonilo** (тот же `type: audio`, без `voice`) генерируются успешно →
  сломана именно TTS-модель/формат голоса, не аудио-конвейер.
- **`ava` — это имя голоса из рабочей UI-фичи Higgsfield.** Пользователь успешно
  сгенерировал им речь в вебе, НО: та генерация в истории списаний называлась
  **«Voiceover»**, а CLI-модель называется **«Text to Speech»**.
  Это РАЗНЫЕ подсистемы. UI-«Voiceover» не появляется в `generate list` и не
  представлена в `model list` (нет job_set_type voiceover; в marketing-studio тоже нет).
- CLI-модель `inworld_text_to_speech` («Text to Speech») отвергает все голоса —
  вероятно ожидает собственный идентификатор/формат, недоступный из CLI и публичных
  доков, либо временно/регионально нерабочая.

## Варианты разблокировки (решение пользователя)

1. **ElevenLabs (fallback спеки фазы 2 §3):** перенести TTS на ElevenLabs —
   новая карточка + бэкенд в higgsfield_client/новом клиенте. Чисто, конвейер
   (audio.json → стадия audio → mix → assemble) не меняется, только источник файла.
2. **Ручной файл из UI «Voiceover»:** скачать готовую озвучку из веб-UI и положить
   как voice-файл вручную (вписать путь в манифест) — одноразово, для демонстрации.
3. **Найти формат `--voice` для CLI:** взять рабочее значение из сетевого запроса
   UI «Text to Speech» (если такая опция есть отдельно от «Voiceover»), или из
   поддержки Higgsfield. Пробовать значения бесплатно (провал авто-рефандится).

Кандидаты-имена Inworld (если формат прояснится): Ashley, Sarah, Timothy, Olivia,
Dennis, Elizabeth, Pixie, Dominus, Luna — ~25 английских; русский Inworld держит отдельно.
