# MMAudio v2 — фоли по готовому видео

Смотрит файл отрезка и делает синхронную дорожку: шаги там, где шагают, лязг
там, где трясут жесть. Синхрон получается по построению, ручной тайминг не
нужен.

## Что он НЕ умеет

Сюжетный звук, источника которого нет в кадре. Гудок баркаса из тумана он не
придумает — это авторское решение, а не наблюдаемый факт. Такие эффекты живут в
списке `sfx` с точным смещением.

## Структура запроса

```
prompt   = "<характер звука>"   # ОБЯЗАТЕЛЕН по схеме, вопреки «модель всё видит сама»
video    = "<URL отрезка>"
duration = <секунды>
```
